# 弓道學習筆記 Kyudo Note

> 從第一次握弓到資深修練，慢慢累積屬於你的弓道成長紀錄。

一個以繁體中文為主的弓道（きゅうどう）學習服務，先從 Web 開始。內容涵蓋文化、技術、裝備與詞彙，並提供個人學習日誌，讓初學者與資深者都能在同一個地方學習與記錄。

## 模塊規劃

| 模塊 | 內容 |
| --- | --- |
| 文化與哲學 | 弓道的歷史由來、流派、禮法與精神（真・善・美、正射必中、射義） |
| 入門指南 | 從找道場、第一堂課到初段審查的路徑 |
| 裝備百科 | 弓、矢、弽（ゆがけ）、弦、道衣袴的選擇與保養 |
| 基本動作 | 以「射法八節」為核心，動態示範頁面＋中文說明 |
| 日文詞彙庫 | 術語漢字・讀音・中文解釋，可搜尋與收藏 |
| 個人學習日誌 | 課程筆記、練習紀錄、裝備採購、文化體驗 |

「問題研究中心」不獨立成模塊，而是以「常見問題」區塊嵌入各篇文章（例如裝備百科的「矢尺幾公分怎麼選」），每筆資料明確標注來源。

## 內容原則

- **基準**：技術與禮法以全日本弓道連盟（ANKF）《弓道教本》為準，流派差異另行註明
- **分層**：每篇文章分「入門」與「深入」兩層，預設展開入門層
- **射法八節視覺**：3D 骨架線稿＋AI 生成圖像，骨架模型與第二階段 AI 姿勢比對共用

## 發展階段

1. **研究與內容底稿** — 歷史、哲學、射法八節、詞彙等資料研究（`docs/research/`）
2. **MVP** — 內容頁面＋個人學習日誌
3. **AI 輔助指導** — 上傳射形影片 → 姿勢骨架分析 → 對照射法八節給出回饋

## 技術方向（暫定）

- Next.js（內容頁靜態生成）
- Supabase（登入、個人日誌、照片／影片儲存）
- 姿勢辨識：瀏覽器端 MediaPipe（第二階段）

## 目錄

- [`web/`](web/) — 網站（Next.js 靜態站）：射法八節 3D 示範、日文詞彙庫。開發方式見 `web/README.md`
- [`tools/pose/`](tools/pose/) — 從示範影片擷取動作、推算深度、匯出網站用的 3D 動作資料
- [`docs/research/`](docs/research/) — 研究資料（歷史與哲學、射法八節分析、禮儀與體配、裝備練習審查、詞彙表）

射法八節的 3D 人形依 Miyako's Kyudo〈弓道入門：射法八節的連貫動作〉（YouTube）的動作重建，網站只發布關節座標，不使用影片畫面，並附原影片連結。
